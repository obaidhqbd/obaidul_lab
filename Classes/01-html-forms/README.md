# HTML Forms: Structure, Labels & Inputs

Forms become much easier when you stop thinking about them as random boxes and start thinking about **relationships**: a form contains controls, labels explain controls, and attributes connect the two.

In this class you will build a compact student registration form using HTML first and CSS second.

## Homework

Complete the four tasks shown in the student workspace. The checks are intentionally small, because understanding one requirement at a time beats copying a giant finished form.
